# Pit Boss Dashboard

A desktop operations dashboard prototype built with Rust and `egui`/`eframe`.

## Current features

- Live floor heatmap placeholder
- VIP activity sidebar
- System status indicator
- Simulated alert button
- 1200 x 800 initial application window

## Requirements

- Rust toolchain with Cargo

## Run

```text
cargo run
```

## Check

```text
cargo check
```

## Project status

This project is an early UI prototype. WebSocket connectivity, live floor data, and heatmap rendering are planned for future development.
